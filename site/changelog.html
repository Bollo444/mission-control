Session 2 · 2026-06-02 · Tuesday

Providers, health monitor & cascade proxy

4 commits · one focused midday session

A tight, focused session: the free-provider catalog, the self-healing health monitor, the OpenRouter cascade proxy, and the docs that explain what the dashboard does and doesn't touch.

  • Midday

    Docs: control plane vs. inference path6ddb91a

    Added a highlighted "How it works under the hood" callout (with a switchboard analogy): Mission Control records intent and monitors health but does not intercept agents' LLM calls — wiring an agent to a model is a machine-local edit to that agent's own config, outside the repo, with no effect on people who clone it.

  • Midday

    OpenRouter free-model cascade proxy5407a0a

    An OpenAI-compatible proxy at /api/route/openrouter/v1 that tries the requested model then cascades through every free model in chunks of three, returning the first that isn't throttled (the native fallback caps at 3). Reads the key from ~/.mission-control, streams the upstream through, and reports cascade depth via X-MC-OR-Fallback-Set. Verified live against a throttled qwen3-coder:free.

  • Midday

    Cross-platform launch + explicit meeting start879453d

    lib/launch.ts now opens a real terminal on macOS (Terminal.app) and Linux (first available emulator) as well as Windows; IDE-open no longer hardcodes cmd.exe. The boardroom no longer auto-convenes — added a "Convene the fleet" gate. README gained the Windows/macOS/Linux platform matrix and a pre-install checklist.

  • Midday

    Free-provider catalog + 6-hour health monitorea605a6

    Added OpenCode Zen, Groq, Cerebras, GitHub Models, Cloudflare Workers AI, NVIDIA NIM and OpenRouter's full free tier — every model id verified live. Split per-agent routing into preferred vs effective. Built the health monitor (lib/health.ts): per-provider probes with auto-failover to a healthy free model and auto-revert on recovery (429s transient), a boot-time 6h scheduler, and Settings status dots, "Check now", a limits panel and a failover badge.
