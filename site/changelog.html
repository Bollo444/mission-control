2026-06-02 → 06-03

Free-LLM gateway & resilience

Added
  • Fleet Gateway — one OpenAI-compatible endpoint in front of every free provider (Cerebras, NVIDIA NIM, Groq, Cloudflare Workers AI, Mistral, GitHub Models, OpenRouter, OpenCode Zen, Local), with cross-provider cascade on 429/5xx, per-provider cooldown, streaming, token auth, and per-agent routing via an X-MC-Agent header. 28dbbba
  • Universal Logs tab — an append-only, time-ordered record of everything Mission Control does: startup, settings / key / routing changes, health sweeps, failovers, every gateway request, agent activity and vault edits. Secrets are never logged. 28dbbba
  • Usage ledger — rolling RPM/RPD/TPM/TPD counters plus success-rate and latency per provider; the gateway pre-skips providers over a known limit. b36fe29
  • Sticky sessions (a conversation stays on one model ~30 min) and vision routing (image requests → vision-capable models only). b36fe29
  • Opt-in encryption at rest — when MC_ENCRYPTION_KEY is set, provider keys are AES-256-GCM encrypted in settings; non-breaking when unset. b36fe29
  • OpenRouter free-model cascade proxy that cascades past throttled free models. 5407a0a
  • 6-hour health monitor with auto-failover to a healthy free model and auto-revert when the preferred recovers; 429s treated as transient. ea605a6
  • Free-provider catalog — OpenCode Zen, Groq, Cerebras, GitHub Models, Cloudflare Workers AI, NVIDIA NIM, plus OpenRouter's full free tier; every model id verified live. ea605a6
Changed
  • Per-agent routing split into preferred (your choice) vs effective (live), so failover can auto-revert. ea605a6
